# 第四问图件合同

使用项目既有 Python / matplotlib 工作流。图件为中文科研定量图及因果假设图，导出300 dpi PNG与保留文字的PDF，白底、蓝橙主色；源数据均为`output_q4_evolution/tables/`下可追溯结果。

1. 因果结构图：时间经N/D中介及剩余技术路径影响能力；显式画出扰动项与未观测混杂风险。箭头表示假设，不表示已证实因果。
2. 样本与演进图：发布日期完整ND子样本与提交日期大样本是不同分析总体；C3历史来源另外展示，不能拼成同口径长序列。
3. 贡献图：中介贡献点估计和按发布机构重抽样的95%区间；配合遗漏混杂压力测试，展示贡献份额的识别边界。
4. 前沿图：Q3资源最优路径上的基础模型条件90%分位能力；主情景区间与算力放缓情景分开，参考日期固定为最后可比观测日。
5. 桥接图：高/中可比层分别拟合；显示Q3目标Loss相对于真实支撑区间的位置，不跨层连线或裁剪出界输入。
6. 逐任务图：MuSR三子任务按随机猜测基线归一化后等权聚合；比较分类型任务得分与C1快照差异，不能用整体汇总替代。
7. 验证图：完整ND模型的机构留出、发布日期阻塞留出与大样本提交日期短期回测分面展示；各面只比较相同目标上的方法。

审查风险：35个完整ND模型、仅10家机构；排行榜提交窗口不足一年；C4为事后快照；高可比桥接支撑窄；12/24个月为条件外推。上述边界必须在图注或相邻正文披露。

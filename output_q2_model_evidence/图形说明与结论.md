# 问题二：从模型选择到参数估计，再到规模权衡

这组图把“为什么共同修正 → 系数如何确定 → 模型意味着什么”接成一条证据链。截图式的幂律曲线和等损失线适合解释模型，却不能单独作为模型选择或参数估计的证据。

## 1. 修正位置的同口径比较

图件：`01_model_comparison.png/pdf/svg`。

记参数项为T_N=A_s N^-α、数据项为T_D=B_s D^-ν。本次新增四个候选：E_s+T_N+T_D；E_s+T_N exp(z)+T_D；E_s+T_N+T_D exp(z)；E_s+(T_N+T_D)exp(z)。质量分支z=θ_Q(1−q_B)，配比分支z=ηh。比较的是修正位置，指数函数形式和已有幂律骨架保持一致。

|候选|质量留出RMSE|配比留出RMSE|
|---|---:|---:|
|无修正|0.207307|0.237195|
|仅参数项|0.073732|0.124957|
|仅数据项|0.122131|0.095787|
|共同修正|0.062225|0.094679|

质量使用450行、45个ND组合，按组合五折留出；固定B1基线，各训练折重新拟合候选的质量系数。配比使用576行，沿用跨尺度相同配方的group，分组五折；每个候选在训练折重新拟合三个来源基线系数及一个配比系数，无修正候选只拟合来源基线。共同修正候选的OOF误差与冻结接口在1e−6内一致。OOF预测＝每条记录由未见过其所在组的训练折产生的预测。

共同修正在质量分支比最佳单项修正降低约15.6%的RMSE，五折均优于仅参数项；配比分支比仅数据项降低约1.16%，五折中四折较低、一折较高。因此支持将共同修正作为这组候选中的主模型，但配比分支没有展示明显、普遍的优势，也未实施显著性检验。质量B7属于半合成数据，不能视为独立真实训练证据。配比检验以既有问题一h构造为条件，并非重新评估问题一选模过程的嵌套检验。

图的用途：接在统一模型提出之后，回答“为什么不是只改其中一项”。这项补充是对已有模型的事后诊断，不倒写成最初已经完成的模型筛选，也不证明该模型优于所有可能的形式。指数形式的正值、参考点归一、单调响应及只增加一个系数，是结构性选用理由；它与其他函数形式的优劣仍需另行比较。

图注：四类修正位置的分组五折留出预测误差。柱高为汇总全部留出预测计算的RMSE，越低越好；两分支的训练目标与来源基线各自校准。候选采用相同分组和误差口径。质量为半合成数据；分支检验不能证明质量与配比联合迁移成立。

## 2. 系数由目标函数的低点确定

图件：`02_parameter_profiles.png/pdf/svg`。

剖面目标＝固定待考察参数，再优化其他可估计参数所得的目标值。左图固定α、ν，每个网格点重新拟合E、A、B，采用原B1对数残差Huber目标、δ=0.01及原参数边界，画J/J_min−1的等值线；星号为现有估计α=0.339985、ν=0.279892。J_min为所绘网格含既有估计点时的最小目标值。窄范围仅用于放大低点附近形状，不是置信区域。

中图固定B1基线，改变θ_Q，展示质量全量拟合RMSE，最低点在θ_Q=0.396659附近。右图改变η，每一点重新拟合RegMix的E_s、A_s、B_s，最低点在η=0.079567附近。右图使用有界线性最小二乘求三个幅度参数，与原对数参数化对应相同正值边界；最小化RMSE和原平方残差目标具有相同解。

图的用途：回答“这些数从哪里来”。它们是数据拟合系数，不是为了让图好看而手选的超参数。曲线低点说明当前数据及目标函数偏好的取值，不代表泛化能力、置信度或真实因果效应；第一张图承担留出检验任务。训练RMSE与第一张图的留出RMSE不同。

必须分清：θ_Q=λs_Q可以估计，λ和s_Q分别不可识别；s_Q=0.5、1、2是尺度情景，不能画成已由数据选出的最优值。7B/140B是解释资源替代时的参考设定，同样不是拟合最优点。Huber阈值、搜索边界等估计设置不因这张图得到“最优性证明”。

图注：模型系数的全量样本剖面目标。α、ν面采用对数Huber目标，其余两图为平方损失对应的RMSE；需要估计的来源幅度参数在每个剖面点重新优化。标记显示既有估计值，等值线及曲线均不表示置信区间。

## 3. 幂律分项与等损失线解释规模权衡

图件：`03_scaling_geometry.png/pdf/svg`。

固定来源为B1，u=h=0，模型退化为L=E+AN^-α+BD^-ν。左图只在B1各自观测范围内画两项贡献，展示增大N或D会降低对应损失项，且边际收益递减。N和D虽均以十亿计，但分别表示参数数和Token数；横轴同一个数值不是同一种资源，也不能用两条曲线的高低直接判断哪个更值得投入。

右图横轴N、纵轴D；同一条等损失线上，较少参数可由更多数据补偿，反之亦然。灰点为B1检查点，同行轨迹上的点不是独立实验。绿色星号(7,140)是条件演示的参考规模。模型曲线是拟合模型的推演，不是额外观测或模型有效性证明。

两条脊线必须区别：橙色虚线满足T_N=T_D，表示两项贡献相等；蓝色点划线满足αT_N=νT_D，表示固定训练算力C∝ND时的最优分配，且暂不考虑供给和其他约束。因为α不等于ν，两线不重合。固定质量、配比时，共同修正乘子不依赖N、D，因此改变损失水平而不改变该算力最优分配条件。

图的用途：承接估计结果，解释参数量与数据量为何需要权衡，并为问题三的资源优化提供条件公式。它与截图的表达形式接近，但明确区分等贡献线与算力最优线，避免把两者混称“最优脊”。

图注：B1基准模型的规模分项与几何解释。左图幂律分项各自限制在观测范围，灰虚线为不可约损失项；右图为模型预测的等损失线，灰点表示检查点覆盖。橙线为两项贡献相等，蓝线为固定ND下的模型最优分配，绿色星号为给定参考点。

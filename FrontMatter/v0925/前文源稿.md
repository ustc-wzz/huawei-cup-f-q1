# 问题重述

## 问题背景

大语言模型的训练需要在参数规模、训练数据量和数据质量之间分配有限算力。增加参数与训练 Token 数通常能降低验证损失，但数据清洗和质量提升同样消耗资源，较长的上下文窗口还会增加注意力开销。领域配比则决定训练数据在不同来源之间的分配。因而，资源配置既要比较规模扩张与质量投入的收益，也要考虑配比变化和上下文长度带来的影响。

经典标度律以参数量和训练量描述损失变化。以十亿参数和十亿 Token 为单位，分别记二者为 $N_B$、$D_B$，其基本形式为：

$$L=E+AN_B^{-\alpha}+BD_B^{-\nu}.\tag{1-1}$$

其中，$E$ 为不可约损失，另外两项分别描述参数规模和训练量不足对应的损失。该形式没有显式区分语料质量与来源结构。题目提供的质量信号、配比实验、训练轨迹和历史能力评测，可以用于补充这些因素；但各类数据的观测单位、质量刻度与评测口径不同，需要分别处理后再建立联系。

## 问题内容

问题一研究数据质量评价与领域配比响应。利用 A1—A3 的全部 22 项质量信号构造综合质量评分，明确指标冲突的判据和处理方式，并在扩展数据上复核；利用 A4—A15 建立 17 域训练份额与 13 域验证损失的关系，在份额非负、总和为一的约束下分析领域调整及候选配方，通过检验集和外推表考察模型的适用范围。

问题二研究包含规模、质量和配比的广义标度律。承接第一问的质量表征与配比响应，引入参数量、训练量、数据质量和领域配比，估计损失模型并进行跨来源、跨尺度检验；分析各因素的边际作用，给出质量提升与规模扩张取得相同损失时的替代条件。

问题三研究算力约束下的资源配置。将基础训练、数据提质与注意力计算纳入共同预算，考察不同预算量级下参数量、训练量及质量投入的选择；比较配比方案、质量成本函数和外生上下文长度的影响，定义并检验最优策略是否发生结构性转移。

问题四研究历史能力增长与未来前沿。利用历史模型评测及训练元数据，区分规模扩张与非规模变化对能力增长的贡献；检查 Loss 与 Benchmark 得分的换算条件，并在算力增速放缓的情景下预测未来 12 个月和 24 个月的能力前沿，给出相应的不确定性与验证结果。

# 问题分析

## 总体技术路线

四问依次处理质量与配比的度量、损失响应的估计、预算下的资源选择，以及历史能力归因和未来前沿。第一问的质量评价与配比回归分别使用两类实验数据，两条支路独立估计，再通过领域映射形成后续接口。第二问将质量增量与配比响应接入经典规模项；第三问以该损失函数为目标，在三项成本的共同约束下求解；第四问承接规模响应和资源配置结果，结合历史评测建立能力模型。总体路线见图2-1。

## 问题一的分析

质量评价首先要解决信号之间不可直接比较的问题。22 项指标既有标量也有分类评分输出，优劣方向、分布形状和篇幅影响各不相同。本文先按字段语义标量化并统一方向，对独特词占比和两项格式指标设置条件参照，再以 A1 的固定分布映射到共同尺度。随后用平方相关衡量指标冗余，降低重复信息的权重。扩展集沿用同一参照，保证质量差异不会被各数据集独立归一化所掩盖。

指标冲突与综合评分承担不同任务。冲突诊断先确定总体负相关的指标对，再检查单篇文本是否同时落入高、低尾部，用于定位分歧及分析成因；综合评分采用指数凹聚合，提高低分维度的边际影响，限制优势指标对明显短板的补偿。评分按文档等权和词数加权分别汇总，结合扩展复核、权重扰动和内容核查评价其稳定性。

配比实验的困难在于份额相互制约：增加某一领域必须减少其他领域。本文以对数混料模型描述 17 域份额与平均损失的关系，用可行份额转移解释边际作用，并在约束内求候选配方；线性混料、加性样条和 GBM 用于比较预测及候选评价。7 个质量域与 17 个配方域通过 A16 建立参考映射，但固定的领域质量随配比加权后仍由配比决定，难以据此识别独立质量作用。因此，质量评分不进入本问配比主模型的拟合，两条支路的输出在第二问中分别接入。

## 问题二的分析

引入质量和配比后，主要困难是不同来源的损失水平与质量刻度不一致。本文保留经典标度律的两项规模响应，用质量增量和标准化配比响应构造共同乘子，使修正同时作用于参数项和数据项；在基线质量、参考配比下恢复经典形式。来源基准与幅度分别校准，第一问的配比响应形状保持固定，以减少跨来源差异与新增效应之间的混淆。

参数采用分阶段估计：先由 B1 拟合规模基线，再估计质量响应和配比修正。质量数据仅能识别响应系数与刻度转换的乘积，因而保留质量尺度情景；同一规模轨迹和重复配方按组划分，防止相关记录同时进入训练与检验。最后从损失函数求边际效用和等损失替代关系，并说明替代成立的范围。这些关系为第三问提供性能目标，但跨尺度误差和质量刻度不确定性仍需随资源情景一并考察。

## 问题三的分析

提质一方面降低损失，另一方面占用本可用于扩大参数量和训练量的算力。本文在参考配比下联合选择 $N_B$、$D_B$ 和质量增量 $u$，以第一问候选配比作对照；上下文长度由 C7 给出，作为外生条件进入注意力成本。质量评分先转换为成本函数所需的刻度，再由域内高分文档的平均增量构造提质上限。不同成本函数、质量尺度和上限分别形成情景，所得配置是这些条件下的最优解。

求解利用损失随训练量下降的性质，将预算约束取等号并消去训练量。固定质量后，在对数参数量上求唯一的规模最优解，再比较整个质量区间内的目标值。以不提质、部分提质和达到上限区分质量状态，用全局收益门槛解释状态切换，并通过连续预算扫描检查是否发生转移。三种状态是判别标准，实际出现哪些状态由计算结果决定；主情景持续达到上限的结果同样保留。

## 问题四的分析

历史能力增长同时伴随参数量、训练量和技术条件变化，直接回归得分与时间难以分开这些作用。本文在元数据完整的基础模型中建立两维规模中介：时间先关联参数量与训练量，再经第二问的规模响应关联能力；控制规模后保留剩余时间路径。通过四种反事实情境比较，将有限时期的能力增量分配给规模与非规模路径，并用分组重抽样、留出检验和混杂敏感性考察分解的可靠程度。非规模解释以评测可比和结构假设为条件。

未来前沿另以条件第 90 百分位描述。历史算力增长经情景折减后形成预算路径，调用第三问求解资源配置，再将规模收益与给定衰减条件下的非规模时间收益接入能力分位模型。C6 的分层桥接用于检验绝对 Loss 的直接换算是否受数据支持；缺少训练量的大样本榜单则按模型类型作趋势对照和短期回测。两类辅助分析分别检验尺度换算与趋势表现，不替代完整规模样本中的历史归因。

# 模型假设

以下假设按其在四问中的作用列出。固定参数和情景取值在相应模型中给出。

**假设1：固定参照下的质量信号具有比较意义。** 指标经语义方向统一及既定标量化后，可以描述文本在相应质量维度上的相对位置；A1 能为 A2、A3 中同类文本提供参考。该假设支持共享变换参数与参照分布，分类方向和评分器本身的偏差仍通过扩展与内容核查考察。

**假设2：指定条件参照能够减弱篇幅和格式的测量差异。** 独特词占比按相近篇幅比较，行末标点与非字母词占比按同领域比较，其余指标保留全局参照。这样处理允许部分观测差异归于文本长度和文体，但不据此认定校准后误判已被消除。

**假设3：同口径样本支持相应的平均质量和配比响应估计。** 标识去重后的域内文本用于估计领域均分；同一尺度、同一训练口径下的配方实验用于估计份额与验证损失的统计关系。A16 的映射及收缩规则提供配方域参考质量，缺少对应样本的领域沿用总体参照，其不确定性不作为新增实测信息处理。

**假设4：规模响应形状可在指定来源与情景间迁移。** 在分别校准损失基准和幅度后，以共享规模指数及冻结的配比响应描述新增来源；额外质量与配比通过共同乘子修正规模损失。质量刻度转换 $s_Q$ 尚未独立识别，故以给定尺度情景传递质量收益；完整尺度留出用于检验迁移范围。

**假设5：题设三项成本可以近似描述资源竞争。** 基础训练和注意力成本正比于 $N_BD_B$，增量提质成本按同一训练量 $D_B$ 计量，上下文长度外生给定。该成本代理没有另计筛选前的原料 Token 需求，也未估计长上下文本身的任务收益；规模外推与训练数据供给因此属于资源结论的适用条件。

**假设6：样本质量差异可用于构造条件提质区间。** 域内最高给定比例文档的均值增量，经既有映射加权后作为质量上限，允许在该区间内连续选择质量投入。缺少质量样本的 11 个配方域冻结基准质量且新增收益取零。上限表示样本参照情景，不代表已经验证的训练 Token 供给能力。

**假设7：历史结构关系在比较时期内可比。** 两维规模扰动可以相关，能力扰动与规模扰动独立，残差分布跨期稳定；在评测口径和规模范围可比、主要混杂得到控制的条件下，将剩余时间路径解释为非规模变化。历史归因限于元数据完整的基础模型，并通过混杂与训练量误差敏感性检查该假设的影响。

**假设8：给定情景下的能力响应可作条件外推。** 算力增速折减、非规模推进半衰期及第三问资源条件共同确定未来路径，历史估计的分位响应在此路径上延用。半衰期与预算情景不是由短期榜单充分识别的参数；预测区间反映所实施重抽样的波动，不涵盖全部结构与外推误差。

| $\rho$ | 混杂压力测试中的假定残差相关 | $[-0.6,0.6]$ | 第九章 |
| $q_\tau,\tau$ | 条件分位响应及分位水平 | $\tau=0.9$ | 第九章 |
| $b_{0,\tau},\kappa_\tau,\gamma_\tau$ | 条件前沿的截距、规模系数与时间系数 | $\kappa_\tau\geq0$ | 第九章 |
| $C_\star,g_C,r_C,C_h$ | 预算起点、历史对数增速、增速保留比例及未来预算 | FLOPs；$g_C$按年计 | 第九章 |
| $h,H,\psi_H(h)$ | 预测月数、技术半衰期、有效推进年数 | 月、月、年 | 第九章 |
| $N_h^*,D_h^*,Q_h^*,L_h^*$ | 第三问在未来预算下的最优资源及损失 | 规模按十亿计 | 第九章 |
| $z_\star,z_h,F_h$ | 起点与未来的分位logit响应、条件能力前沿 | $F_h=100\operatorname{expit}(z_h)$ | 第九章 |

$\pi_i=\operatorname{clip}(S_i/100,0.001,0.999)$，仅在计算logit时截断。第六章的 $\theta_Q$ 是质量摘要回归斜率，第七章同名符号表示由质量实验识别的参数，二者按所在模型区分。$T$、$G$、$r$、$z$、$\rho$ 等局部符号也按表列章节使用。$Q_s$ 在结果图中亦记作 $Q_{\mathrm{res}}$；文档词数加权与训练 Token 量分别计量。

## 质量信号的预处理

A1 覆盖 arxiv、book、c4、commoncrawl、github、stackexchange 和 wikipedia 七个质量域；A2、A3 分别补充 arxiv 与 github。14 项标量信号与 8 项列表信号先整理成每篇文本 22 个数值。二分类输出经稳定 softmax 转为目标类别概率，ModernBERT 六级输出取概率加权期望，教育价值取单元素值，QuRating 取四分量均值并另存原分量。流畅度和广告类别方向依据 A1 领域对照作代理判定，确定后冻结；该处理不等于已独立核验评分器标签。具体规则见表5-2。

表5-2 质量指标的方向及字段处理

| 指标 | 方向 | 标量化或特殊处理 |
|:--|:--|:--|
| 教育价值 | 正向 | 单元素列表取唯一数值 |
| 英文流畅度 | 正向 | 二分类logits转为流畅类概率 |
| 干净度、可读性、推理性、专业性 | 正向 | 各自取六级概率加权期望；专业性保留全局参照 |
| DSIR书籍、维基、数学信号 | 正向 | 三项分别除以$\max(\text{文档词数},1)$ |
| QuRating评分 | 正向 | 四个分量的算术平均 |
| 一元词熵 | 正向 | 保留数值后统一尺度 |
| 独特词占比 | 正向 | 使用A1相近长度文本的分位参照 |
| 行末标点占比 | 正向 | 使用A1同领域分位参照 |
| 广告概率 | 负向 | 二分类logits转为广告类概率后反向 |
| 非字母词占比 | 负向 | 反向后使用A1同领域分位参照 |
| 高频二元组、高频三元组占比 | 负向 | 各自反向后统一尺度 |
| 大写字母、数字字符占比 | 负向 | 各自反向后统一尺度 |
| 文档词数、句子数、平均词长 | 区间型 | 合理区间为平台，偏离后降低效用 |

对不可解析值及正负无穷记为缺失，以 A1 相应指标的有效中位数填补，并将同一填补值用于扩展集；若 A1 任一指标全部缺失，则停止质量评分并核查该字段。22 项信号按 13 项正向、6 项负向和3项区间型处理。词数的合理区间为50—100,000，句数为3至A1第95百分位，平均词长为3—10；词数与句数先取对数坐标，再计算区间型效用。各指标的尺度端点仅由 A1 确定，扩展数据复用并截断越界值。

独特词占比以 A1 词数建立20个等频组，删除重复分界，不拆分同词数记录，并将不足500条的小组与相邻组合并；行末标点与非字母词占比采用 A1 同领域参照，其余19项采用全局参照。参照内并列值取中秩百分位，经端点截断后映射为正态分数 $Z_{sj}$；其定义与第六章式（6-1）一致。所有区间参数、分组边界和参照分布固定用于 A2、A3，输出同一尺度的质量矩阵，供第六章赋权与聚合。

单独评分保留 A1—A3 的集合身份；合并领域质量时按“领域＋文档标识”去重，272,505条输入得到261,086篇文本。该步骤消除标识重叠，不替代跨标识的全文近重复检测。文档等权均值与词数加权均值分别保留，词数仅作为篇幅权重，不直接等同于分词器统计的训练 Token 数。

## 配比实验的预处理

配比表与损失表按实验标识 index 连接，检查标识唯一性、匹配数量和领域列顺序。保留全部17个训练域及13个验证域，结构零不删除；仅对有限、非负且行和为正的份额向量按行归一化，以修正舍入引起的总和偏差。综合响应取13域损失等权均值，同时保留逐域响应。四个没有同名验证损失列的训练域仍保留份额，缺失目标不补零。

A4/A5 的512组配方用于1M训练集内的嵌套五折比较与选参；A6—A11按1M、60M、1B尺度分别构成冻结模型后的检验集；A12—A15仅作10B、70B外推一致性检查。第二问再次使用 A6—A11 校准配比修正时，按完整配方分组，并另作完整尺度留出。由于这些数据已经用于第一问检验，后续校准结果不再称为整个建模链的独立检验。

## 标度律数据的预处理

统一参数量、训练量和损失字段，对进入损失拟合的数据检查有限性与正值，参数量和训练量分别以十亿为单位。基础训练算力相应按 $6\times10^{18}N_BD_B$ FLOPs 计算。B1 保留参数规模与检查点标识，按完整参数规模留出；B2 的半合成轨迹与 B3 的插值轨迹保留各自性质，B4、B5 则在来源内部校准基准与幅度，不把不同来源的损失水平直接混为一条轨迹。

B6 与 B7 按参数量、训练量和质量值三字段核查重叠：B6 的360条记录全部包含于 B7，且损失相同；B7共450条，新增90条来自质量0.5与0.7。主质量拟合使用去重后的 B7，并按45个完整参数量—训练量组合分组验证；B6到B7新增质量水平另作迁移检查。B8的组内质量—损失方向与B6、B7相反，保留为方向审计和纳入敏感性，不并入主质量参数估计。B9、B10分别保留元数据和估算损失身份，用于大尺度情景核对。

## 评测与模型元数据的预处理

C1先按许可证允许列表、有效提交日期、正参数量及六项任务得分完整性筛选，再按模型仓库去重，保留最早有效提交，最终得到2449个模型。IFEval、BBH、MATH Lvl 5、GPQA、MuSR和MMLU-PRO的归一化得分等权形成综合能力；仅计算logit时将比例截断至[0.001,0.999]，原得分保持不变。该样本用于类型对照，并不要求每个模型都有完整训练量。

C1与C4按规范名称、参数规模及命名空间核对，确定性匹配69个模型。其中同时满足基础模型、权重开放、非明显混合专家、有效发布日期及完整参数量和训练量的35个模型进入历史归因，按10个仓库命名空间作发布方代理分组，缺失训练量不填补；完整样本采用与训练量配套的C4参数量，排行榜参数量另留作核对。C4另筛出截至2025年3月13日的215个模型估计算力趋势；C3中的26条历史文献记录用于来源与年份覆盖检查，不与排行榜得分直接拼接回归。

时间口径随分析对象分别保留：历史归因按发布日期计算，零点为2023年1月1日；分类型趋势按提交日期计算，零点为2024年6月1日；季度算力趋势以2022年1月1日为零点。未来12个月和24个月的主预测从最后有效提交日2025年3月13日起算。C6按高、中可比性分层建立Loss—能力桥接，C5仅核对重叠记录；超出各层观测Loss范围的换算保持缺失。C7的2048、4096、8192、32768、131072五个窗口作为外生配置情景。

C8保留原始文件并记录解析状态，每个目录选择时间戳最新且可解析的评测。1958个JSON中有4个损坏文件，其中1个目录存在有效替代，其余3个目录退出逐任务分析，最终得到1860个可解析模型。MuSR按谋杀推理、物体放置和团队分配三个叶子任务重建，猜测基线分别为1/2、1/5、1/3；对选项长度归一化准确率逐项扣除猜测基线、按剩余区间缩放并截断负值，再在三项齐全时等权平均。重建值用于核对汇总口径，不覆盖C1得分。数据筛选、匹配和异常处理记录与模型结果分别保存，供后续检验追溯。

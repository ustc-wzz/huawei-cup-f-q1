## 版本区分

采用语义版本标签 `v主版本.次版本.修订号`：模型或实验流程改变增加次版本；格式和文字修正增加修订号；不兼容的整体框架变更增加主版本。日期、具体修改及验证结果记录在 CHANGELOG.md。

- `v0.1.0`：修改前基线，GBM主预测与候选接口。
- `v0.2.0`：对数线性主模型与解析配比接口，GBM辅助核查。

每次修订完成后完整验证、提交并创建带说明的版本标签，然后同步分支和标签到GitHub。文件名保持稳定，版本由Git管理；`notebook_source.py`是包含Markdown的文本镜像，便于查看改动。

查看版本：`git log --oneline --decorate`；查看两个版本的源代码变化：`git diff v0.1.0 v0.2.0 -- 0924_F题_问题一.ipynb`。GitHub可通过Tags切换版本，通过Compare比较两版。
